# 阻值线径速算器 (WireCalc App)

> 基于物理公式 $R_1 \times r_1^2 = R_2 \times r_2^2$，输入任意 3 个数，自动计算出第 4 个数！

---

## 📌 计算原理与四种情况公式

根据导线电阻定律：$R = \rho \cdot \frac{L}{S} = \rho \cdot \frac{L}{\pi (r/2)^2} = \frac{4\rho L}{\pi r^2}$
在相同材料和长度下，电阻与导线直径的平方成反比：$R \times r^2 = \text{常数}$。

即等式关系：
$$R_1 \times r_1^2 = R_2 \times r_2^2$$

无论已知哪 3 个数，求第 4 个数的计算公式如下：

| 求解目标 | 计算公式 | 说明 |
| :--- | :--- | :--- |
| **求 直径2 ($r_2$)** *(原图红圈)* | $$r_2 = \sqrt{\frac{R_1 \cdot r_1^2}{R_2}}$$ | 已知阻值1、直径1、阻值2 |
| **求 阻值2 ($R_2$)** | $$R_2 = \frac{R_1 \cdot r_1^2}{r_2^2}$$ | 已知阻值1、直径1、直径2 |
| **求 直径1 ($r_1$)** | $$r_1 = \sqrt{\frac{R_2 \cdot r_2^2}{R_1}}$$ | 已知阻值2、直径2、阻值1 |
| **求 阻值1 ($R_1$)** | $$R_1 = \frac{R_2 \cdot r_2^2}{r_1^2}$$ | 已知阻值2、直径2、直径1 |

## ✨ App 功能特性

1. **智能感应计算**：4个输入框任意填写 3 个，剩余 1 个立即自动计算出结果，无需手动切换模式。
2. **公式步骤展示**：给出详细的代入过程与计算公式，方便核对检验。
3. **原图示例一键带入**：一键填入 $R_1=54$, $r_1=17.5$, $R_2=110$，秒出结果 $r_2 \approx 12.261358$。
4. **一键复制与清空**：支持一键将计算结果复制到剪贴板，一键清空所有输入。
5. **轻量无广告**：基于 Android 原生架构，极速启动，体积仅数 MB。
