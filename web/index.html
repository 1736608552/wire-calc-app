📐 物理原理与计算公式

• 原理：导线电阻 R = ρ·L/S，由于圆面积 S ∝ r²，在材质与长度不变时，阻值与直径的平方成反比：R₁ × r₁² = R₂ × r₂²。


• 求 直径2 (r₂) [原图红圈]：
r₂ = √(R₁ × r₁² / R₂)

• 求 阻值2 (R₂)：
R₂ = (R₁ × r₁²) / r₂²

• 求 直径1 (r₁)：
r₁ = √(R₂ × r₂² / R₁)

• 求 阻值1 (R₁)：
R₁ = (R₂ × r₂²) / r₁²
